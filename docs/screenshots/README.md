# Screenshots

Portfolio screenshots are **not fabricated** in-repo.

After running the local stack or a real deployment:

1. Open the executive overview, competitive, supporting, scenarios, and explorer pages.
2. Capture PNG/WebP images at desktop width.
3. Save files here with descriptive names, e.g. `overview-desktop.png`.
4. Optionally link them from the README once real files exist.

Do not invent metrics in captions. Use only values already shown by Gate 7B/8.
