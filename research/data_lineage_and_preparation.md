## 2. End-to-end flow for numbers used in Gates 5–6

```
SOURCE (MW secondary articles, APJII via Kompas, GoTo/TikTok PR, …)
    ↓  manual curation + provenance notes
RAW CSVs under data/raw/…
    ↓  python/ingestion/load_raw.py
DATAFRAME IN MEMORY
    ↓  python/cleaning/clean.py
    - typing (year/share/GMV numeric)
    - platform name canonicalize
    - entity_type normalize
    - sort; KEEP missing as NA
    ↓  python/validation/validate.py
PROCESSED CSVs under data/processed/…
    ↓  Gate 3–5.5 research curation (entity_split, 2025_comparable, gate5 CSV)
    ↓  Gate 6 scenario input assembly
    ↓  python/prepare_analysis_ready.py  (this milestone)
ANALYSIS-READY competitive_panel.csv
    ↓
Gate 5–6 narrative analysis / scenarios (docs; conclusions unchanged)
```

### Trace example: “Shopee 54% in 2025”

1. **Source:** Bisnis citing Momentum Works Ecommerce SEA 2026  
2. **Raw:** `market_position_indonesia_mw_public_excerpts.csv` row year=2025 platform=Shopee share=54  
3. **Clean:** numeric share; platform=Shopee; entity_type=standalone  
4. **Processed:** `market_position_indonesia.csv`  
5. **Analysis-ready:** phase=`phase3_post_break`, value_status=`OBSERVED`, comparability=`DIRECT`  
6. **Analysis:** Gate 5/6 Shopee vs Combined comparison  

### Trace example: “Tokopedia 38% in 2025” — INVALID

Correct lineage: Combined entity 38% in raw/processed as `Tokopedia + TikTok Shop` / `combined`.  
Analysis-ready labels analytical_entity=`Combined Tokopedia + TikTok Shop`, comparability=`NOT COMPARABLE` to Legacy history.  
**Legacy Tokopedia 2025 share** appears only as `value_status=UNKNOWN`, value=null.

## 3. Cleaning & transform steps that actually run

| Step | Performed? | Where | Notes |
|------|------------|-------|-------|
| Source extraction | Yes (manual) | `scripts/acquire_data.py` + curated CSVs | Trends blocked |
| Schema inspection | Yes (implicit) | loaders + validators | Fail on missing required cols |
| Data typing | Yes | `clean.py` | year/share/GMV/dates |
| Column naming | Partial | Canonical platform map | No wholesale rename of all datasets |
| Missing-value handling | Yes | Keep NA; no fill | Explicit UNKNOWN rows for Legacy 2025 |
| Duplicate handling | Yes | Validators flag duplicate keys | |
| Unit/currency | Partial | GMV in USD billions as sourced; IDR fees separate | No FX invent |
| Percentage bounds | Yes | Validators 0–100 | |
| Year/date normalize | Yes | to_numeric / to_datetime | |
| Categorical normalize | Yes | platform canonicalize; entity_type lower | |
| Derived calculations | Yes (documented) | Additive Combined 2024 = 23+11 in prepare script & Gate 3–5 tables | Labeled DERIVED |
| Structural-break labeling | Yes | entity_type combined; phase labels; COMPARABILITY.md | |
| Scenario handling | Yes | gate6 outputs value_type=SCENARIO | Not mixed into OBSERVED panel as fact |
| Validation | Yes | process_data + prepare_analysis_ready + smoke tests | |

**Not performed (do not claim):** ML imputation, annual→monthly interpolation, Combined−TTS Legacy residual as OBSERVED, Google Trends ingest.
